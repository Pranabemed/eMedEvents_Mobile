Dropdown UI update

Reference: Profile > Contact > Country uses CheckoutModaltwo's standardized DropdownPanel in src/Components/DropDownHeader.js. Its existing colors, fonts, search border/radius, row spacing, header, close icon and highlight styles are reused, not redesigned.

Updated coverage:
- Profession, specialty, country, state, city and year selectors used by Profile, All Special, state/license setup, certificates, credits, Checkout, Register Interest and Contact Us.
- CreditVault state and board selectors; board, credit type and mandatory topic selectors.
- Employment status, hospital, travel mode, conference format and course status lists.
- Explore profession/state filters, guest profession/specialty selectors and Checkout custom ticket dropdowns.
- Shared closed-field placeholder text now uses Select [Field Name]. Existing input-box shapes are retained.
- Required search markers render separately from the TextInput query; optional Contact Us selectors explicitly suppress them.

Scope and behavior:
Only dropdown presentation and regression tests were changed during this task. Existing APIs, payloads, validations, navigation and dependency logic were retained. AST comparison found zero existing screen event callbacks removed or changed. Native date/calendar controls, upload controls, normal editable inputs, and non-dropdown page content retain their existing presentation. Lists which previously had no search retain that behavior; no new filtering logic was introduced. Existing dropdown hosting (inline, screen, or modal) remains in place.
